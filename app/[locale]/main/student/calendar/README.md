# app/main/student/calendar

A single page: fetches `fetchClassBySelfCalendar()` (`app/lib/actions/classes.actions.ts`, session-derived — no id/email param needed since it reads the current session internally) and renders `WeeklySchedule` (`app/ui/main/calendar/weekly-schedule.tsx`) with `basePath="/main/student"`, which is what makes the calendar's drag-to-schedule flow and class-block clicks route into the student side of the app (`/main/student/classes/request`, `/main/student/classes/[id]`) rather than the teacher side. Falls back to an empty array if the fetch returns `null` (unauthenticated — though in practice the layout above this page should already have redirected an unauthenticated user before this renders). No other logic — all the calendar's actual behavior (drag geometry, timezone bucketing, live "now" line) lives in the `WeeklySchedule`/`CalendarClassCard` components themselves; see `app/ui/main/calendar`'s README.
