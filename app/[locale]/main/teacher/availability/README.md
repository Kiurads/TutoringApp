# app/main/teacher/availability

A single page: auth-gated (redirects to `/login` twice over — once if there's no session, once more defensively if `fetchUserByEmail` somehow returns nothing for a valid session), fetches `fetchAvailability(user.id)` (`app/lib/actions/availability.actions.ts`) and renders `AvailabilityGrid` in its default **edit mode** (no `readOnly` prop passed) — this is the only place in the app `AvailabilityGrid` is used for editing rather than display; every other usage (`TeacherAvailabilityView` on a profile page) is read-only. All the actual interaction (click/drag painting, presets, save) lives in the grid component itself — see `app/ui/main/availability`'s README. The page copy explicitly tells the teacher "Students will see these slots when browsing your profile," which is the read-only `TeacherAvailabilityView` surface elsewhere in the app.
